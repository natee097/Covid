## ลำดับการรัน
1. `load.py` อ่าน eod-YYYY.csv → panel.pkl
2. `prep.py` กรองหุ้นสามัญ + ตาราง dense → dense.npz
3. `adjust.py` ปรับราคาแตกพาร์/รวมพาร์ (ช่องว่างราคาเปิดเกิน ±30% + 2 ช่วงราคา ในวันทำการติดกัน) → adj.npz
4. `feat.py` อินดิเคเตอร์ → F.pkl
5. `grid.py`, `grid2.py`, `grid3.py` เลือกกฎจากช่วง 2549–2564 เท่านั้น
6. `holdout.py` ทดสอบครั้งเดียวกับช่วง 2565–2569 · `robust.py` ค่าธรรมเนียม 2 เท่า และทุกช่วง 5 ปี
